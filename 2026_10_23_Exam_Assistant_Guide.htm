第一階段：三步引導結構資料庫

PROMPT TEMPLATE 
你是一位教學經驗豐富的國中小各科命題與學習診斷專家。
我已經上傳了本次段考考卷（如未附解答，請先以最嚴謹的步驟解出正確答案）。

請為這份考卷的每一道題目建立「三步引導自主訂正資料庫」。
為了讓學生配合手邊的「實體紙本考卷」思考，並由平板 Canvas 進行思維導航，請嚴格遵守以下輸出規範：

【各題分析架構】
每一題請依序輸出以下欄位：
1. 【題號與正解】：標註題號與正確答案選項（例：第 3 題 / 正解：(B)）。
2. 【第一步・破題關鍵字與審題指引】：
   - 提取審題最核心的 1~2 個關鍵詞。
   - 若本題有「幾何圖形、實驗裝置、數據圖表、地圖或長文本段落」，請在此特別加上【看圖/看題指引】，明確提示學生：「請對照紙本考卷第 X 題圖形，特別觀察……（具體指出圖中值得注意的線索，如刻度、角度、交點或變化趨勢）」。
3. 【第二步・核心概念與公式】：寫出解開本題所需的單元觀念、定理定義或計算公式（不要代入數值計算）。
4. 【第三步・拆解式引導問句】：設計 2 個由淺入深的思考問句，絕對不能直接說出答案或選項，引導學生透過回答這 2 個問題自行推導出結果。

【輸出格式限制】
- 請務必將所有題目的內容，完整包覆在一個「單一的 Markdown 程式碼區塊」內輸出（即以 ```markdown 開頭，並以 ``` 結尾）。
- 嚴禁中斷程式碼區塊，方便我點擊右上角「複製（Copy）」一鍵帶入下一階段的 Canvas。

第二階段：Canvas 互動訂正站指令（數理專業版）

PROMPT TEMPLATE 
請在 Canvas 中為我建立一個「段考三步引導自主訂正 Web App（數理專業版）」。

【重要：數學式 LaTeX 專業渲染規格】
1. 請在 HTML 的 <head> 中引入 KaTeX CDN（含 katex.min.css、katex.min.js 及 auto-render.min.js）。
2. 確保網頁內所有數學式、分數、根號、幾何符號（如 $ngle$、$	riangle$）均使用 LaTeX 語法渲染（行內公式使用 $...$，獨立區塊使用 $$...$$）。
3. 當學生切換題號、或 AI 在右側對話框產生新訊息時，必須主動呼叫 renderMathInElement 確保動態文字也能即時渲染成美觀的數學式。

【版面架構】
1. 頂部或左側選單：提供所有題號按鈕，點擊可快速切換當前訂正題目。
2. 左側卡片（思維導航儀）：
   - 題號與正確答案標註。
   - 【第一步・破題關鍵字與審題指引】：包含文字關鍵字與【看圖指引】（提醒學生核對桌上紙本考卷對應圖表）。
   - 【第二步・核心概念與公式】：預設摺疊或設計成「點擊展開概念提示」按鈕（公式需標準 LaTeX 渲染）。
   - 【第三步・拆解式引導問句】：列出 2 個關鍵思考問句。
3. 右側面板（AI 專屬教練對話框）：
   - 提供對話歷程與學生文字輸入框。
   - 學生切換題號時，AI 自動送出對應該題的親切開場，邀請學生回答左側的第三步問句。

【內建 Gemini AI 對話核心邏輯】
1. 階段一【思維引導】：
   - 學生回答問句時，給予針對性反饋，引導其逐步推導出正確答案，絕對禁止在學生自己想出前直接說出選項或解答。
   - AI 若提到數學運算式、分數或變數，一律使用標準 LaTeX 格式（如 $rac{a}{b}$、$\sqrt{x}$）輸出。
2. 階段二【通關結算與類題邀約】：
   - 學生推導出正解時，AI 給予肯定並總結 1 句觀念。
   - 主動詢問：「觀念通了！要不要挑戰一題『平行類似題』確認自己徹底搞懂？（請回答：好 / 下一題）」
3. 階段三【現場出題與批改】：
   - 若學生同意挑戰：AI 依據原題的核心概念與題型，現場生成 1 道「難度相當、觀念相同但數字改變」的文字類題（含選項），請學生作答。
   - 學生回答後，AI 立即批改、解析並總結。
4. 階段四【收尾導流】：
   - 完成類題後，主動提示：「這題訂正完成！請在左側點選下一題繼續訂正。」
